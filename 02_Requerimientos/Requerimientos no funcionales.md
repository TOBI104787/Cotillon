El sistema deberá:

-El sistema debe tener una interfaz sencilla de usar. 
-El tiempo de respuesta del sistema debe ser de menos de 1 segundo. 
-El sistema debe ser compatible en dispositivos Windows y Linux, computadoras de escritorio y notebooks. 
-El sistema debe guardar los datos de forma permanente. 
-Ser confiable para el registro de ventas y gastos.
