#**El sistema deberá:**

1. El sistema debe tener una interfaz sencilla de usar.
2. El tiempo de respuesta del sistema debe ser de menos de 1 segundo.
3. El sistema debe ser compatible en dispositivos Windows y Linux, computadoras de escritorio y notebooks.
4. El sistema debe guardar los datos de forma permanente.
5. Ser confiable para el registro de ventas y gastos.
